## Overview

Companion package for the article *Density estimation for compositional data using nonparametric mixtures* (Xie, Wang, and García-Portugués, 2026), including:

-   simulation
-   real data application
-   tables / figures

## Directory structure

```         
project/
├── data/   
│ ├── raw/    # Raw (immutable) data
│ └── processed/    # Cleaned data (generated by scripts)
├── R/    # General-purpose functions
├── scripts/    # Analysis pipelines (call functions from R/)
├── models/   # Trained models saved as .rds
├── results/
│ ├── raw/    # Raw outputs from simulation and real data application
│ ├── tables/   # Tables for the paper (aggregated results from raw/)
│ └── figures/  # Figures for the paper
```

## Requirements

-   R version: 4.4.1 (or later)
-   R packages:\
    `compositions`, `zCompositions`, `gtools`, `ks`, `npden`, `lsei`, `MLmetrics`, `rgl`, `misc3d`, `tidyr`, `dplyr`, `viridis`, `paletteer`, `magick`

## Data

The folder `/data/raw` stores the raw datasets, while `/data/processed` contains the cleaned datasets generated by the scripts.

-   *National GDP Dataset*: the processed dataset `gdp2023.rds` is generated from raw datasets `GDP.xlsx` and `OGHIST_2025_07_01.xlsx` using the script `gdp_clean.R`.
-   *USPS Dataset*: no processed dataset is required. The raw datasets `usps_train.rds` and `usps_test.rds` are used directly.
-   *Pratheepan Dataset*: the processed datasets `pratheepan_traskin.rds`, `pratheepan_traoth.rds` and `pratheepan_test.rds` are generated from raw datasets in folders `Pratheepan_Dataset` and `Ground_Truth` using the script `pratheepan_cls.R`.

## Replicability

The folder `/scripts` contains the scripts to replicate the simulation and real data application of the paper.

-   The script `plot_fig1.R` generates contours of the Dirichlet distribution (Figure 1).
-   The script `plot_fig2.R` illustrates the Modal EM process on the gradient function (Figure 2).

For simulation:

-   The script `plot_simu.R` generates contour plots of Gaussian and Dirichlet mixture simulations (Figures 3--6) and plots computation time recorded during the simulations (Figure 7).
-   The script `simulation.R` reproduces the simulation experiments and aggregate simulation results (Tables 1--2, 4--5).

For real data application:

*National GDP Dataset*

-   The script `gdp_clean.R` cleans the dataset for analysis.
-   The script `plot_gdp.R` generates scatter plots of GDP compositions (Figure 8a), contour plot from the Dir-CVKLD model (Figure 8b), and classification results by income group (Figure 9).
-   The script `gdp_simu.R` reproduces the simulation experiments and aggregate simulation results (Table 7).

*USPS Dataset*

-   The script `plot_usps.R` generates marginal contour plots from the Dir-CVKLD model (Figure 10).
-   The script `usps_cls.R` reproduces digits classification experiment and reports classification performance (Table 8).

*Pratheepan Dataset*

-   The script `pratheepan_cls.R` reproduces skin detection experiment and reports detection performance (Table 9).
-   The script `plot_pratheepan.R` generates decision boundary for skin detection (Figure 11).

## Models and results

The folder `/models` stores trained mixture models in `.rds` format, provided for convenience to reproduce figures and tables without retraining. All models can also be regenerated by running the corresponding scripts in `/scripts`.

The folder `/results` contains all outputs generated from simulations and real data applications:

-   `raw`: raw outputs from individual runs (large, not directly used in the paper).
-   `tables`: aggregated results used to generate tables in the paper.
-   `figures`: figures in PDF or PNG format, directly included in the paper.
